# Backend Quickstart ⚡

Get your development environment running in 15 minutes.

---

## Prerequisites

Before starting, ensure you have:

| Tool | Version | Check Command |
|------|---------|---------------|
| Python | 3.13+ | `python3 --version` |
| Node.js | 18+ | `node --version` |
| Firebase CLI | Latest | `firebase --version` |
| Git | Any | `git --version` |

### Installing Firebase CLI

```bash
npm install -g firebase-tools
firebase login
```

---

## Step 1: Clone the Repository

```bash
git clone <repository-url>
cd landing
```

---

## Step 2: Set Up Python Environment

```bash
# Navigate to functions directory
cd functions

# Create virtual environment
python3 -m venv venv

# Activate virtual environment
source venv/bin/activate  # macOS/Linux
# Windows: venv\Scripts\activate

# Install dependencies
pip install -r requirements.txt
```

> [!TIP]
> Always activate the virtual environment before working on the backend:
> ```bash
> cd functions && source venv/bin/activate
> ```

---

## Step 3: Configure Environment Variables

Create `functions/.env` for local development:

```bash
# Required for AI endpoints
GEMINI_API_KEY=your-gemini-api-key

# Development mode (permissive CORS)
ENVIRONMENT=development
```

### Getting a Gemini API Key

1. Go to [Google AI Studio](https://aistudio.google.com/apikey)
2. Click "Create API Key"
3. Copy the key to your `.env` file

> [!WARNING]
> Never commit `.env` files. They're already in `.gitignore`.

---

## Step 4: Run the Firebase Emulator

From the project root (`landing/`):

```bash
# Start all emulators (Auth, Firestore, Functions)
firebase emulators:start
```

You'll see output like:


## Step 5: Verify Your Setup

### Run Tests

```bash
cd functions
source venv/bin/activate
pytest
```

You should see all tests pass with 95%+ coverage.

### Test an Endpoint (Optional)

With emulators running, test the health endpoint:

```bash
curl http://127.0.0.1:5001/<project-id>/us-central1/health
```

Replace `<project-id>` with your Firebase project ID.

## Troubleshooting

### "Python 3.13 not found"

Install Python 3.13:
```bash
# macOS with Homebrew
brew install python@3.13

# Or use pyenv
pyenv install 3.13.0
pyenv local 3.13.0
```

### "Module not found" errors

Ensure virtual environment is activated:
```bash
source venv/bin/activate
pip install -r requirements.txt
```

### "Firebase emulators won't start"

Check if ports are in use:
```bash
lsof -i :5001  # Functions
lsof -i :8080  # Firestore
lsof -i :9099  # Auth
```

Kill processes using those ports, or change ports in `firebase.json`.

### "Tests fail with import errors"

Make sure you're in the `functions/` directory:
```bash
cd functions
pytest
```

## Quick Copy-Paste Setup

For the impatient, here's the full setup in one go:

```bash

git clone <repository-url>
cd landing/functions

# Python environment
python3 -m venv venv
source venv/bin/activate
```
